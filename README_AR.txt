مكتبة قوالب قص اسكرينات ظهر الموبايلات — الإصدار الأول
====================================================

الموجود حاليًا:
- بحث باسم الشركة/الموديل.
- قائمة مبدئية: Redmi Note 9S وVivo Y26 وVivo Y27.
- مفضلة.
- إضافة أسماء وملاحظات قوالب محليًا في متصفح الجهاز.
- معاينة توضيحية وتنزيل SVG/طباعة.
- PWA مع ملفات manifest وservice worker.

تنبيه مهم:
الرسمة الحالية نموذج تخطيطي للتأكد من عمل التطبيق فقط، وليست قوالب دقيقة لأي موديل.
لا تستخدمها لقص خامة فعلية أو للبيع. يجب إدخال قياسات موثوقة والتحقق من فتحة الكاميرا
والحواف والانحناءات وتجربة نسخة مطبوعة قبل اعتماد أي قالب.

التشغيل من أندرويد:
1) ارفع الملفات كلها إلى مستودع GitHub جديد.
2) من إعدادات المستودع افتح Settings > Pages.
3) اختر Deploy from a branch، ثم main و/(root)، ثم Save.
4) افتح رابط GitHub Pages الناتج في Chrome على أندرويد.
5) من قائمة Chrome (⋮) اختر Install app أو Add to Home screen.

ملاحظات:
- يجب نشر الموقع عبر HTTPS حتى يعمل التثبيت والعمل دون اتصال.
- البيانات المحلية محفوظة داخل المتصفح على هذا الجهاز؛ مسح بيانات المتصفح قد يحذفها.
- إضافة قالب الآن تحفظ الاسم والملاحظات فقط، ولا تُنشئ قالب قص هندسيًا دقيقًا تلقائيًا.
- الطباعة يجب أن تكون A4 وبمقياس 100%/Actual Size، وليس Fit to page.
